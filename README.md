# korelacja

## opis
Gra w zgadywanie współczynnika korelacji liniowej na podstawie wykresu dwóch zmiennych.


## instalacja
Gra do działania wymaga zainstalowania języka R oraz bibliotek shiny, shinyWidgets oraz ggplot2. Można to zrobić własnoręcznie lub odkomentowując 5 pierwszych linijek pliku. Pakiety zostaną zainstalowane w podfolderze "packages" w miejscu pliku.
